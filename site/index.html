글로 쓰면,
데이터가 움직입니다.

a -> b 한 줄이 한 단계. ene는 텍스트로 쓴 데이터 흐름을 점이 실제로 오가는 다이어그램으로 바꿉니다.

Write the flow. Watch the data move.

06
ene flow.ene → .svg

    

      
README에 그대로 붙는 움직이는 SVG

      
CLI로 만든 SVG는 스크립트 없이 스스로 반복 재생됩니다. GitHub에서도 반복 재생됩니다. 분기가 있으면 첫 갈래만 나와요.

      

        
# SVG 만들기 (--lang ko 로 오류 메시지를 한국어로)
$ ene 01-order.ene -o 01-order.svg

        
# README.md 에 붙이기
![주문 흐름](docs/01-order.svg)

        
# 두 번째 갈래로 내보내기
$ ene 03-cache.ene --choice 1

      

      

        
README.md 미리보기 · 아래는 <img src="01-order.svg"> 한 장입니다

        

      

      
이 SVG는 CLI가 내보낸 실제 결과물입니다. 다크 모드(prefers-color-scheme)와 모션 줄이기, 스크린 리더용 설명을 스스로 따릅니다. 그래서 위 그림은 이 페이지 테마가 아니라 보는 사람의 OS 테마를 따릅니다.

    

  







  

    
07
ene · Mermaid · D2

    

      
비슷한 도구와 나란히

      
Mermaid와 D2는 훌륭한 도구이고, 다이어그램 종류는 둘이 훨씬 많습니다. ene는 흐름을 설명하는 일 하나에 집중합니다.

      

        

          
기능eneMermaidD2

          
            
데이터가 경로를 따라 움직임있음 — 점이 엣지를 따라 이동flowchart 엣지 애니메이션(점선 흐름, v11+)엣지 선 애니메이션

            
단계별 재생 · 이전/다음있음 — 재생, 정지, 단계 이동, 속도없음보드(board) 단위 애니메이션

            
분기를 골라 재생있음 — 플레이어에서 갈래 선택없음없음

            
움직이는 SVG 내보내기있음 — 스크립트 없는 SVG엣지 애니메이션 포함 SVG여러 보드를 이은 애니메이션 SVG

            
한국어 오류 메시지있음 — 위치와 “혹시 ○○인가요?”영어영어

            
시퀀스 다이어그램있음있음있음

            
다이어그램 종류흐름도 · 시퀀스매우 많음많음

            
GitHub 기본 렌더링없음 (SVG로 내보내 붙이기)있음없음

          
        

      

      
2026-11 기준 요약입니다. 최신 지원 범위는 각 공식 문서를 확인해 주세요.
